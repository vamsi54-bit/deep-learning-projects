# NeuroSight

AI-Powered Brain Tumor Detection and Diagnostic Report Generation

## Overview

NeuroSight is a full-stack AI application that detects and analyzes brain tumors from MRI scans.

The system:

* Segments tumor regions using U-Net
* Classifies tumor type using EfficientNet-B3
* Generates AI-powered diagnostic reports using Claude API
* Provides a modern web interface using React and Tailwind CSS
